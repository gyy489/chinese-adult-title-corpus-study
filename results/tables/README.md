# Aggregate result tables

All CSV files in this directory contain aggregate counts, proportions,
intervals, or agreement statistics. They contain no title text, title hashes,
record identifiers, evidence spans, source-site names, or URLs.

## Main results

- `corpus_pipeline_counts.csv`: corpus formation and final sample composition.
- `table_1_corpus_formation.csv`: candidate frame, valid outputs, deduplication,
  and analytical sample.
- `table_2_target_actor_visibility.csv`: primary within-title target–actor
  visibility comparison.
- `table_3_cross_stage_consistency.csv`: secondary cross-stage label
  consistency.
- `table_4_supporting_and_sensitivity.csv`: target composition, exploratory
  person-position cues, and authorization-boundary sensitivity.

## Supplementary aggregates

- `supplement_s1a_*` and `supplement_s1b_*`: heuristic intervals and paired
  contrasts.
- `supplement_s2a_*` through `supplement_s2d_*`: sampling-composition, quality,
  sensitivity-range, and authorization-boundary summaries.
- `supplement_s3_*`: field-level cross-model diagnostics.
- `supplement_s4*`: aggregate human-review accuracy and agreement summaries.

Intervals are descriptive heuristics for possible superpopulation reasoning;
they are not sampling-error statements for the fully analyzed retained corpus.
